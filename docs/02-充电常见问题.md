# 充电常见问题（演示样例数据）

> 说明：本文件为本地 Demo 演示用样例，具体操作以车辆手册和充电桩厂商说明为准。

## 充电枪插上没反应，怎么排查
1. 先确认车辆处于挂 P 挡、车门已解锁状态，部分车型需要在车机上确认开始充电。
2. 检查充电枪是否插到位，听到锁止声后再观察车机充电界面。
3. 更换一个充电桩或一根充电线测试，排除桩体或线缆故障。
4. 检查家充插座漏电保护器是否跳闸，接地是否正常。
5. 以上都无效时，记录车辆报警信息，联系服务站检测充电口和车载充电机。

## 慢充与快充
- 交流慢充（家充桩 / 交流桩）功率较低，适合夜间停放补能，对电池更友好。
- 直流快充功率高，适合长途应急补能；频繁快充会影响电池老化速度，日常以慢充为主。
- 快充一般充至 80% 后会降速，属于正常保护策略，不建议每次都充到 100%。

## 充电注意事项
- 雨天可以正常充电，但要保持充电口干燥，禁止枪头沾水后强行插拔。
- 长期停放建议电量保持在 30%–60%，每月补电一次，避免电量过低损伤电池。
- 充电过程中不要强行拔枪，先在车机或 App 上停止充电，等待解锁后再拔出。

## 常见报错提示
- 若提示“充电连接异常”，优先重新插拔并检查接口有无异物、水渍。
- 若提示“电池温度过高/过低”，等待温度恢复到正常区间后再充。
- 重复出现同类报错，需到服务站读取充电系统故障码。
